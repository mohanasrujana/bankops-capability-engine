# LedgerDesk

LedgerDesk is the synthetic legacy-style banking application used to demonstrate BankOps Capability Engine.

Its first workflow lets an operator search for a synthetic member, open account details, and read a savings balance. Controlled states will cover success, member not found, invalid input, transient interruption, permission denial, and an action requiring human approval.

LedgerDesk must never contain real customer data, credentials, or personally identifiable information.
